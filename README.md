# Multilingual Love Heart

A Python desktop animation that builds a heart from expressions meaning “I love you” in 20 languages. The words appear with a floating entrance effect, then continue to shimmer against a dark background.

**Owner:** Ronaldo Diergaardt

![Multilingual love heart animation](https://github.com/user-attachments/assets/6c2ccffe-f46d-4b2f-9430-36a6a5739beb)

## Features

- Arranges multilingual phrases inside a heart-shaped outline.
- Animates the phrases into place with color and glow effects.
- Adds a subtle shimmer after the heart has been drawn.
- Uses Python's standard-library `turtle`, `tkinter`, `math`, and `random` modules.

## Requirements

- Python 3
- A desktop environment that supports Tkinter

No third-party Python packages are required.

## Run

From the project directory, run:

```powershell
python love.py
```

The animation opens in its own window. Close the window to exit.
